## Types de missions

| Type | Description |
|------|-------------|
| Cutscene | Mission entièrement ou presque entièrement en cinématiques |
| Quest | Mission avec beaucoup de déplacements et cinématiques |
| Dungeon | Mission se déroulant dans un donjon (Promyvion, Sacrarium…) |
| Fight | Mission centrée sur un ou plusieurs combats de NM |
| BCNM | Mission se terminant par un BCNM |
| Repeatable | Mission répétable pour gagner des Rank Points |

> Si les Rank Points sont insuffisants pour démarrer la prochaine mission, trader des cristaux à un Conquest Guard pour en obtenir davantage.
